Qué hace este modo automáticamente

  1. Ingresa el Excel y la carpeta de fotos a cuarentena, igual que en Ingresos.
  2. Genera el dry-run y lo prepara: crea las identidades pendientes de revisión para esa marca.
  3. Indexa las fotos y vincula automáticamente las que coincidan exactamente con el nombre de archivo de una referencia ya aprobada.
  4. Te lleva directo a revisar las identidades nuevas. Las fotos de productos nuevos se vinculan solas recién cuando los apruebes ahí — después vuelve a Imágenes para completarlas.

Nada se publica en el catálogo todavía: seguís necesitando aprobar cada identidad y, más adelante, construir y publicar una versión desde Catálogos.
